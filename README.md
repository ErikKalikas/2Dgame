# Lower Tier


## Запуск

Нужен [Node.js](https://nodejs.org/) 18+.

```bash
npm install      # один раз
npm start        # запускает игру и открывает браузер
```

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | автотесты логики (генерация мира, характеристики, контент) |
| `npm run build` | сборка в папку `dist/` |
| `npm run typecheck` | проверка типов |
| `npm run app` | запуск как ПК-приложение (окно Electron) |
| `npm run dist:win` | сборка `release/Lower-Tier-…-portable.exe` для Windows |
| `npm run dist:linux` | сборка `release/Lower-Tier-….AppImage` для Linux |

Exe и AppImage работают без установки: скачал и запустил. F11 переключает полноэкранный режим.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Стрелки | стрельба в 8 направлениях (правая рука) |
| Shift | фокус: медленное точное движение, виден хитбокс |
| Space | рывок (короткая неуязвимость, можно перепрыгнуть яму) |
| E | левая рука: модуль руки (щит, гарпун, клинок…) или толчок манипулятором; с двуручным оружием недоступно |
| R | взять / купить / лифт / операция; удерживать у запертой двери — взлом |
| F | сбой: 2 с вне системы, пули рядом переписываются и летят во врагов |
| Q | активный модуль |
| Esc | пауза |
| P | новый забег в новом мире |

**Сбой.** Шкала заряжается, когда пули пролетают вплотную к хитбоксу (чем ближе, тем больше), и немного за убийства. В начале уровня она полная. Если сбой заряжен и в тебя попали, есть 0,15 с, чтобы нажать F и отменить попадание (аварийный сбой).

**Оружие** бывает одноручным и двуручным. Двуручное занимает обе руки, и атака на E недоступна.

**Тело.** Подобранные модули и скелеты кладутся в рюкзак (3 места, больше — с сумкой и баулом). Ставить, снимать и менять модули можно только в **операционной** — она есть на каждом уровне. Слоты: голова, левая и правая рука, корпус, ноги, спина; ещё четыре системы тела открываются боссами 2, 4, 6 и 8-го уровней. **Скелет** класса 1–4 ограничивает редкость модулей. В правую руку можно поставить **руку-оружие** (сильнее ручного оружия, меняется только на операции). Прошивки работают сразу.

**Энергоячейки** — валюта магазинов. Запертую сокровищницу вскрывают, удерживая R у двери.


**Враги и их наборы.** Киборги роняют свои модули и оружие, роботы — прошивки. Чем ценнее враг, тем реже дроп (15 / 10 / 7 / 5%), но тем больше предметов в его наборе (3–6) и тем они сильнее. Каждое убийство без дропа немного повышает шанс с этого вида врагов. Предмет набора выпадает за забег один раз; когда набор собран, вместо него падают энергоячейки. Над врагом с несобранным набором — жёлтая метка; «Сканер утильщика» показывает шанс.

**Нестабильность.** Предметы тяжёлых и элитных врагов несовместимы с телом. Чем их больше, тем выше уровень нестабильности (1–4, виден внизу слева). При потере жизни один такой предмет может отключиться — на время, до конца боя или до конца уровня. На высоких уровнях бывают помехи интерфейса и случайные бонусы.

В **настройках** можно выключить метки наборов и помехи нестабильности.
