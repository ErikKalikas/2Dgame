# Lower Tier


## Запуск

Нужен [Node.js](https://nodejs.org/) 18+.

```bash
npm install      # один раз
npm start        # запускает игру и открывает браузер
```

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | автотесты логики (генерация мира, характеристики, контент) |
| `npm run build` | сборка в папку `dist/` |
| `npm run typecheck` | проверка типов |
| `npm run app` | запуск как ПК-приложение (окно Electron) |
| `npm run dist:win` | сборка `release/Lower-Tier-…-portable.exe` для Windows |
| `npm run dist:linux` | сборка `release/Lower-Tier-….AppImage` для Linux |

Exe и AppImage работают без установки: скачал и запустил. F11 переключает полноэкранный режим.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Стрелки | стрельба в 8 направлениях (правая рука) |
| Shift | фокус: медленное точное движение, виден хитбокс |
| Space | рывок (короткая неуязвимость, можно перепрыгнуть яму) |
| E | левая рука: толчок манипулятором (отбрасывает врагов); с двуручным оружием недоступно |
| R | взять / купить / лифт |
| F | сбой: 2 с вне системы, пули рядом переписываются и летят во врагов |
| Q | активный имплант |
| Esc | пауза |
| P | новый забег в новом мире |

**Сбой.** Шкала заряжается, когда пули пролетают вплотную к хитбоксу (чем ближе, тем больше), и немного за убийства. В начале уровня она полная. Если сбой заряжен и в тебя попали, есть 0,15 с, чтобы нажать F и отменить попадание (аварийный сбой).

**Оружие** бывает одноручным и двуручным. Двуручное занимает обе руки, и атака на E недоступна.
