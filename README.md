# BLACK ICE


## Запуск

Нужен [Node.js](https://nodejs.org/) 18+.

```bash
npm install      # один раз
npm start        # запускает игру и открывает браузер
```

Другие команды:

| Команда | Что делает |
|---|---|
| `npm test` | автотесты логики (генерация мира, характеристики, контент) |
| `npm run build` | сборка в папку `dist/` |
| `npm run typecheck` | проверка типов |
| `npm run app` | запуск как ПК-приложение (окно Electron) |
| `npm run dist:win` | сборка `release/BLACK-ICE-…-portable.exe` для Windows |
| `npm run dist:linux` | сборка `release/BLACK-ICE-….AppImage` для Linux |

Exe и AppImage работают без установки: скачал и запустил. F11 переключает полноэкранный режим.

## Управление

| Клавиша | Действие |
|---|---|
| WASD | движение |
| Стрелки | стрельба в 8 направлениях |
| Shift | фокус: медленное точное движение, виден хитбокс |
| Space | рывок (короткая неуязвимость, можно перепрыгнуть яму) |
| F | ЭМИ-бомба: стирает все вражеские пули |
| Q | активный имплант |
| E | взять / купить / телепорт |
| Esc | пауза |
| P | новый забег в новом мире |

## Структура кода

```
src/
  core/      ввод, генератор случайных чисел с seed, локализация, настройки
  gfx/       палитра, спрайты (генерируются кодом), отрисовка
  world/     генерация этажей и комнат
  game/      игровая логика: игрок, враги, пули, бой, предметы, HUD
  content/   данные: оружие, импланты, модификации, синергии, враги, боссы, этажи
  scenes/    экраны: меню, игра, пауза, настройки, кодекс, конец забега
tests/       автотесты (Vitest) и браузерные проверки (Playwright)
```

Как добавить предмет: допишите объект в `src/content/weapons.ts`, `implants.ts` или `passives.ts`.
Поля описаны в `src/game/items.ts`, характеристики — в `src/game/stats.ts`.

Решения, принятые по ходу разработки, — в `DECISIONS.md`. План — в `PLAN.md`.
